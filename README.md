# AI Prompt Macro

AI Prompt Macroは、PC版Chrome / Edgeで選んだChatGPTタブへ、事前に決めた指示を順番に送るローカルのブラウザ拡張です。**ChatGPTの回答本文は読み取りません。** 同じ指示の繰り返しや、指示・待機・確認ポイントを組み合わせた手順を実行できます。

**原作者 / Original author:** [tomoponz](https://github.com/tomoponz)

Fork、改善提案、Issue、Pull Requestを歓迎します。

**現在の配布版: 0.4.0**。[Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/ai-prompt-macro/faefckjniohmhndofpbbgfkkoemfialp)で **Live** になっています（2026年9月15日確認）。配布設定は **Hidden**、ストア掲載文は日本語・英語です。

同じ指示を繰り返すQuick Prompt（クイックプロンプト）と、複数の指示を記述するAIPM Flowに対応しています。変更点と検証記録は[v0.4.0リリースノート](https://github.com/tomoponz/ai-prompt-macro-public/releases/tag/v0.4.0)を参照してください。ソースから手元に読み込む場合は、下の「ローカルにインストールする」を参照してください。

AI Prompt Macroは独立したプロジェクトであり、OpenAIとの提携やOpenAIによる承認を示すものではありません。ChatGPTは自動操作の対象となる第三者のサービスです。[プライバシーポリシー](https://tomoponz.github.io/ai-prompt-macro/privacy.html) / [MIT License](LICENSE)

自動実行先は **`https://chatgpt.com/`のみ**、1回の実行で自動送信は最大50回です。送信結果や対象ページが不明な場合は停止し、同じ指示を自動再送しません。

OpenAI API・APIキー・独自サーバーは使いません。回答の収集や回答内容による分岐、CAPTCHA・利用上限の回避は行いません。

## 最初に使う

1. サイドパネルの **「操作するChatGPTタブ」** で、会話タイトル（手動の表示名があれば優先）を確認して対象を選びます。「操作対象」は送信先、「表示中」はこのウィンドウで開いているタブです。表示中のタブへ送信先が自動変更されることはありません。タブID・会話IDは「詳細」で確認できます。
2. 同じ指示を繰り返すなら **「クイック」** で指示・繰り返し回数・待機時間を設定します。
3. 異なる指示を並べるなら **「手順を貼り付け」** を開きます。必要なら **「AIに手順を作ってもらう」** のガイドをコピーしてAIへ自分で渡し、返されたAIPM Flowを貼り付けます。
4. 対象タブ、実行する指示と順序、送信予定数、接続状態を確認し、**「この内容で自動送信を開始（N回）」** を押します（Nは送信予定数）。

Flowの貼り付け・検証・ガイドのコピーだけでは送信しません。開始時に確認した内容を保存して照合するため、通常のFlow入力ではワークスペースへの移動や手動保存は不要です。入力だけして確認するDraft、部分実行、ライブラリなどの詳細操作は **「ワークスペース」** → **「Flow / ワークフロー編集」** を使います。開始・一時停止・再開・停止はサイドパネルで行います。

[はじめて使う](docs/getting-started/README.md)では、インストールから次のFlowの貼り付け・確認・実行まで、現在の画面名に沿って説明しています。

```text
指示A → 待機3秒 → 指示B → 待機3秒 → 指示C
```

新しい会話から始める場合、最初の送信ボタン操作後に **「確認が必要」** で止まります。同じタブで、作成された会話と最初の指示が1回だけ送られたことを確認して **「再開」** を押してください。最初の指示は再送しません。

## できること

| 機能 | 操作する場所 |
| --- | --- |
| 同じ指示を指定回数繰り返す | サイドパネル「クイックプロンプト」 |
| AI向けガイドをコピーし、Flowを貼り付けて確認・開始 | サイドパネル「手順を貼り付け」 |
| 指示・待機・指定時刻・確認ポイントを組む | ワークスペース「ワークフローエディター」 |
| AIPM Flowをテキストで編集・検証・プレビュー | ワークスペース「Flowエディター」 |
| Flowの保存・読み込み・書き出し | ワークスペース「Flowライブラリ」「読み込み / 書き出し」 |
| 入力欄へ指示を置き、自動送信せず確認する | 指示の動作「入力だけして確認」 |
| 実行状態・理由・次の操作の確認と実行操作 | サイドパネル「実行コントロール」 |
| 複数タブの保存済み実行記録を閲覧 | ワークスペース「実行一覧」 |
| 外観や、新しい実行内容の既定値を変更 | 「設定」 |

ワークフローは手順を画面で組み立てる方式、AIPM Flowはテキストで記述する方式です。現在のFlowには「入力だけして確認」の構文はありません。編集・保存・読み込みだけでは開始しません。実行操作は、サイドパネルで明示選択したタブだけが対象です。別タブでAIに手順を作ってもらっても、実行対象は追従変更しません。

## ローカルにインストールする

1. このリポジトリをZIPでダウンロードして展開するか、Gitでcloneします。
2. Chromeでは `chrome://extensions`、Edgeでは `edge://extensions` を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**（Load unpacked）を選び、`manifest.json`があるフォルダーを指定します。
5. ChatGPTへログインし、拡張を読み込んだ後にそのタブを一度再読み込みします（Ctrl+R）。
6. 拡張機能アイコンからAI Prompt Macroのサイドパネルを開きます。

ビルドは不要です。自動操作はPC版ChatGPT Webに限ります。スマートフォン、Claude、Geminiの画面やOpenAI APIには対応していません。サイドパネルの **「AIに手順を作ってもらう」** とワークスペースの **「ヘルプ・AIヘルパー」** は、AIへ手動で渡す共通の作成ガイドをコピーするだけで、自動連携しません。

## 安全性とプライバシー

### 回答本文を読まない（Output-Blind）

回答本文を取得・保存・解析・送信・書き出しせず、回答による条件分岐にも使いません。入力欄、送信・生成状態の操作部品、限定された制限・確認画面、会話識別に必要なURL情報を確認します。

ChatGPTタブのページタイトルは、サイドパネルで見分けるための一時表示にだけ使います。タイトルから送信先や会話の同一性を判断せず、Run・送信記録・診断情報や永続ストレージへ保存しません。開発者へ送信することもありません。ChatGPTの回答本文を読まないOutput-Blindの方針は維持しています。

Output-Blindは、ブラウザ権限による物理的な隔離ではなく、監査可能な実装上の制約です。`chatgpt.com`で動くスクリプトには技術上ページへのアクセスがあります。詳しくは[プライバシー（実装の詳細）](PRIVACY.md)を参照してください。

「前の回答を踏まえて改善して」と送ることはできますが、文脈を利用するのはChatGPT側です。拡張は文脈の保持範囲や回答内容を確認しません。

### 不確かな状態では自動継続しない

- 対象タブ・会話・ページや操作部品を安全に確認できない場合は停止します。表示名・識別色・グループを送信先の判断には使いません。
- 送信処理の記録を事前に保存し、入力内容と安全条件を確認して送信ボタンを1回だけ操作します。既存の下書き・添付を上書きしません。
- 送信結果が不明な場合は、同じ指示を自動再送しません。
- **送信確認済みでも、生成完了や次の準備状態を確認できず停止する場合があります。** 送信済みという確定は維持し、同じ指示は自動再送しません。
- 同じ会話を複数の自動化から同時に操作することを防ぎます。
- CAPTCHA・ログイン要求・利用上限・サービスエラーを突破しません。
- 最大50回の自動送信という上限を、画面だけでなく実行時にも検証します。

<details>
<summary>送信確認の技術的な範囲</summary>

送信前に、指示本文のハッシュを含む送信記録（outbox）を保存します。入力欄が空であることと、書き込んだ指示が完全に一致することを確認してから、検証済みの送信ボタン（Send）を1回だけクリックします。入力欄のクリアと生成状態の操作部品を確認できた場合だけ、送信確認済み（delivery confirmed）として扱います。`prepared` / `submitted`のまま中断された通常送信は、結果が曖昧なため自動再開しません。永続保存された送信確認済み（durable confirmed）の状態は、後続の確認に失敗しても、より不確かな状態へ格下げ（downgrade）しません。

</details>

## スリープ・再読み込み・再起動

サイドパネルの **「スリープ防止」** は実行中だけPC本体の自動スリープを抑えるよう要求します。画面は消灯でき、一時停止・停止・完了でその実行の要求を解除します。有効な実行が複数あれば最後の1つが止まるまで維持します。

すでにスリープ中のPCを起こしません。手動スリープ、蓋を閉じる操作、OSの設定を必ず上書きする保証もありません。

| 操作 | 動作 |
| --- | --- |
| ChatGPTページを再読み込み（Ctrl+R） | 同じタブ・同じ会話で、安全を確認できる状態だけ継続可能。送信結果が不明なら停止 |
| サイドパネルの「拡張を再読み込み」 | 開発版更新用。全タブに実行中・一時停止中の自動化がないことを確認できる場合だけ許可。更新後はChatGPTページも再読み込み |
| ブラウザ内部のバックグラウンド処理が再生成 | 同じブラウザ起動中なら保存状態と安全条件を再確認。無条件の継続ではない |
| ChatGPTタブを閉じる | そのタブの実行を続行不可にし、指定時刻の予定と編集内容を削除 |
| Chrome / Edgeを完全終了して再起動 | 以前の実行は自動継続せず、指定時刻の予定・スリープ防止・タブ別編集内容・選択対象を解除・消去 |

ブラウザを閉じたまま指定時刻に起動して送信する用途には使えません。Flowライブラリへの明示保存とタブ別編集内容の保存は別です。詳しくは[ユーザーガイド](docs/user-guide/README.md)を参照してください。

## 使用する権限

- `storage`: 手順・設定・実行状態・送信記録・診断情報のローカル保存
- `sidePanel`: サイドパネルの表示
- `alarms`: 同じブラウザ起動中の「指定時刻まで待つ」
- `power`: 有効にした実行のスリープ防止
- `scripting`: 接続できない場合、選択したChatGPTタブへ同梱スクリプトを再接続
- ホストアクセス: `https://chatgpt.com/*`のみ

`tabs`、`history`、`cookies`、`webRequest`、`<all_urls>`は要求しません。独自サーバーや利用状況の外部収集はありません。実際に送信した指示は通常のChatGPT利用としてChatGPT側へ送られ、アカウントの料金・制限・規約が適用されます。

## 開発

実行時の追加依存関係やビルド処理はありません。

```bash
npm install
npm run check
npm test
npm run browser:install
npm run test:browser:smoke
npm run test:browser:full
git diff --check
```

ブラウザテストは、隔離したChromium環境へ拡張を読み込み、ネットワークへ送信しないChatGPTのfixtureで実行します。初回は`npm run browser:install`でテスト用Chromiumを用意します。

Nodeテストとブラウザfixtureは安全条件の回帰検出用です。現在のChatGPT本番画面や、配布対象のChrome / Edgeでの受け入れ確認を代替しません。リリース前にチェックリストの実ブラウザ項目を別途確認してください。
