# AI Prompt Macro

AI Prompt Macro（APM）は、PC版Chrome / Edgeで選んだChatGPTの会話に、あらかじめ決めた指示を順番に送るブラウザ拡張機能です。OpenAI APIやAPIキーは使わず、画面上の入力欄と送信ボタンを操作します。回答本文を読み取ったり、回答の良し悪しを評価したりすることはありません。

この文書はソース版 **0.4.4** を対象にしています。原作者：[tomoponz](https://github.com/tomoponz)。

<a id="できること"></a>
## 何ができるか

| 使い方 | 設定すること |
| --- | --- |
| 単純繰り返し | 同じ指示、繰り返す回数、追加の待機時間 |
| 手順を指定 | 異なる指示と待機などを並べたAIPM Flow |

1回の実行で自動送信できるのは最大50回です。開始前に、対象の会話・送る本文・順序・予定回数を確認できます。実行中は一時停止・再開・停止を操作できますが、再開できるかどうかは停止した理由と状態によって決まります。

ワークスペースでは、手順の詳細編集、Flowの保存・読み込み、指定時刻までの待機、確認ポイントの設定も行えます。なお、「入力だけして確認」はワークフローエディターの機能であり、Flowの構文には含まれません。詳しくは[ユーザーガイド](docs/user-guide.md)を参照してください。

## 向いている用途

- 「前の回答を踏まえて推敲して」など、同じ指示を続けて何度か送る。
- 「案を出す → 問題点を挙げる → 修正案にまとめる」のように、決めた手順で検討を進める。
- 異なる会話にそれぞれ別の指示を設定し、並行して進める（同じ会話の同時自動操作は防ぎます）。

前の回答を文脈として引き継ぐのはChatGPT側の仕組みです。APMが回答を読み取って別の会話へ渡したり、結果に応じて次の指示を選び直したりすることはありません。出力された成果を採用するか、作業を続けるかの判断は利用者が行います。

<a id="ローカルにインストールする"></a>
## 導入

自動操作の対象は **PC版Chrome / Edgeの `https://chatgpt.com/`** のみです。スマートフォン、ClaudeやGeminiの画面、OpenAI APIは操作対象にしていません。

ソース版は次の手順で読み込めます。ビルド作業や`npm install`は不要です。

1. このリポジトリのZIPをダウンロードして展開するか、Gitでcloneします。
2. Chromeでは`chrome://extensions`、Edgeでは`edge://extensions`を開きます。
3. デベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」（Load unpacked）から、`manifest.json`があるフォルダーを選びます。
4. ChatGPTにログインし、入力欄に下書きがあれば退避してから対象タブを再読み込みします。
5. 拡張機能アイコンからAPMのサイドパネルを開きます。

既存の手動導入版を更新する場合は、下書きや未保存の設定を退避し、全タブの実行を止めてから[更新手順](docs/releases/0.4.4.md#既存の手動導入版を更新する)に従ってください。拡張機能とChatGPTページの両方を再読み込みする必要があります。

[Edge Add-onsの掲載ページ](https://microsoftedge.microsoft.com/addons/detail/ai-prompt-macro/faefckjniohmhndofpbbgfkkoemfialp)もありますが、ストア版とこのソース版が同一とは限りません。[検証状況と未確認の範囲](docs/verification.md)と、導入時に表示される版を確認してください。

<a id="最初に使う"></a>
## 基本操作

1. 新しい会話では、まずChatGPTで最初の指示を手動送信し、回答が終わるのを待ちます。会話IDのない新規チャットではAPMを開始できません。
2. サイドパネルの「操作するChatGPTタブ」で対象を選びます。表示しているブラウザタブを切り替えても、送信先は自動で変わりません。
3. 「単純繰り返し」に指示・回数・「追加の待機（秒）」を設定するか、「手順を指定」にFlowを貼り付けます。手動送信済みの指示は除き、これから自動送信する分だけを設定してください。APMは手動送信分を自動で差し引きません。
4. ChatGPTの入力欄と添付を確認します。入力欄に既存の文字がある場合、それを残した末尾へ最初の指示を追記して一緒に送ります。送るつもりのない下書きは退避し、未送信の添付やアップロード中のファイルがない状態にしてください。
5. プレビューで対象・本文・順序・予定回数を確認し、「この内容で自動送信を開始（N回）」を一度押します。貼り付け・検証・保存だけでは送信されません。
6. 終了後は、実際の会話で送信された内容と回答を確認します。「完了」は予定した手順を終えたという意味であり、回答の品質を保証する表示ではありません。

追加待機は、回答の生成完了を確認した後に加える待ち時間です。回答が設定秒数で終わるという意味ではありません。実行中は対象の会話を切り替えたり、入力欄・添付を手動で変更したりしないでください。

コピーして試せる短い例は[はじめて使う](docs/getting-started.md)、止まったときの対処は[ユーザーガイド](docs/user-guide.md)にまとめています。

<a id="安全性とプライバシー"></a>
## 制約・注意点

<a id="回答本文を読まないoutput-blind"></a>
- **回答の内容は扱いません。** 入力欄、送信・生成の操作部品、限定した制限表示などを確認します。回答本文を読まない方針（Output-Blind）はコードとテストで監査する実装上の制約であり、ブラウザ権限でページ本文を物理的に隔離する仕組みではありません。[データの取り扱い](PRIVACY.md)
- **同じ実行内では、送信確認済み・結果不明の指示を自動再送しません。** 画面上で送信を確認できても、その後の生成完了を確認できずに止まる場合があります。その場合も送信済みの記録は維持します。
- **長文や添付への対応は条件付きです。** APMの入力がChatGPT側で添付形式に変わった場合、入力の経緯や認識できる構造などを確認します。添付全文との一致は検証せず、無関係な添付を常に区別できる保証もありません。既存の未確認添付を送信・削除する機能ではありません。[条件と限界](docs/user-guide.md)
- **停止はAPMの今後の自動操作を終えます。** ChatGPTが生成中の回答を止めたり、既送信の指示を取り消したりはしません。一時停止後も、再開可能と表示された状態で対象と入力欄を確認してから再開してください。
- **保存表示が「実行中」のまま残る場合があります。** ページ側の処理は止まっていても、停止要求元と保存された実行の関係を確認できない場合、別の実行を誤って止めないよう保存状態を変更しません。必要な診断と送信済みの範囲を確認し、対象の実行を明示的に「停止」してください。
- **実サービスの動作保証ではありません。** 0.4.4のmain CIは成功していますが、模擬画面での試験と実ChatGPTでの確認は別です。使用中拡張の更新・同一性確認と、0.4.4の実ChatGPTでの最終確認は未実施です。[根拠と未確認事項](docs/verification.md)
- **ChatGPTの利用条件はそのまま適用されます。** ログイン、利用上限、CAPTCHAを回避しません。画面仕様の変更や接続状態によって実行できなくなる場合があります。

<a id="不確かな状態では自動継続しない"></a>
再開や開始を繰り返す前に、画面の「理由」「次の操作」と実際の送信内容を確認してください。再開可能な未送信入力、送信確認済みの生成待ち、結果不明の停止は、それぞれ扱いが異なります。

<a id="スリープ再読み込み再起動"></a>
スリープ防止や再読み込み・ブラウザ再起動の扱いは[ユーザーガイド](docs/user-guide.md)にまとめています。ブラウザを閉じた状態から自動起動して送信する機能ではありません。
