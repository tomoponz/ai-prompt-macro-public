## 証拠ごとの読み方

| 種類 | 確認できること | この記録の範囲 |
| --- | --- | --- |
| ソース確認 | 実装された制御や制約 | 開始・対象確認・入力・送信確認・生成待ち・停止／復旧を[コード案内](../architecture/README.md)に整理。実サービスでの動作証明ではありません |
| テストの存在 | 想定する回帰条件 | [tests](../../tests)にNodeテストとブラウザfixtureがあります。ファイルがあるだけでは成功扱いにしません |
| 自動試験の結果 | 対象コミットが、その試験条件を通ったこと | 上記CIの構文確認、Nodeテスト、ブラウザfull・repeat・resource-cardの各stepが成功 |
| 実際の利用 | その版・ブラウザ・サービス画面での結果 | 0.4.4を使用中の拡張へ適用した実ChatGPT最終確認と、配布対象Chrome / Edgeでの受け入れ確認は未実施 |
| インストール版の同一性 | 読み込み中の実装が検証対象と同じこと | 読み込み元パスとファイル内容の照合は未完了。バージョン表示や拡張IDだけでは確認済みにしません |

ブラウザfixture試験は、隔離したChromiumと模擬画面（fixture）を使用します。現在のChatGPTの実際のDOM構造、サービス制限、アカウント状態をすべて再現するものではありません。また、このCIではtorture・release・theme-renderの各コマンドは実行していません。今回の文書整理にあたっては試験の新規実行は行わず、公開GitHub上の既存CI結果を照合しています。各試験の実行方法は[開発と試験](../development/README.md)を参照してください。

## 過去の報告と、残っている確認

ストア配布について、旧READMEには2026年9月15日時点でEdge Add-ons版0.4.0がLive（公開設定はHidden）であるという記録が残っています。今回の文書整理では、[現在のストア掲載ページ](https://microsoftedge.microsoft.com/addons/detail/ai-prompt-macro/faefckjniohmhndofpbbgfkkoemfialp)における最新の版・状態は再確認していません。ソース版0.4.4と同一のものとして扱わず、導入時に実際に表示されるバージョンを確認してください。

[0.4.4のリリース記録](../release/0.4.4.md)には、過去の版における短文20回の連続送信や、長文が添付形式になった場合の送信成功に関する利用者報告が記載されています。一方で、長文の反復中に停止したという報告もあります。これらはすべて過去の版に関する報告であり、0.4.4の実利用確認の証拠としては引き継ぎません。[反復停止の調査](../release/repeat-stop-investigation.md)と[添付カードの検証範囲](../release/resource-card-r2.md)も、それぞれ記載された対象版・条件とあわせて読む必要があります。

今後、実サービスでの動作を確認する際は、[PCリリースチェックリスト](../release/PC_RELEASE_CHECKLIST.md)に沿って、拡張機能の読み込み元とコミットの対応、Chrome / Edgeのバージョン、試験内容、送信済みの範囲、停止理由を記録します。短文・長文、途中停止・再開、ページ再読み込みを分けて確認し、送信結果が不明になった指示を確認目的で自動再送しないでください。

なお、APMの送信確認は入力欄と生成状態のUI観測に基づくものであり、回答の品質を評価するものではありません。長文が添付化された場合も、添付全文と元の指示の一致を検証する仕組みではありません。既知の制限事項は[0.4.4](../release/0.4.4.md)、利用者向けの具体的な対処手順は[ユーザーガイド](../user-guide/README.md)を参照してください。
