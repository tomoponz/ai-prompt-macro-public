## 文書の置き場所

単独の説明ページはこのフォルダー直下に置き、版別の変更履歴は`releases/`、配布手順は`distribution/`、過去の調査は`history/`に分けています。公開プライバシーポリシーは既存の`store/`にあります。

以前のURLには、対応する新しい本文への案内を残しています。古い見出しへのリンクからも、その節へ進めます。文書の本文は新しい場所で管理します。

自動試験やCIの成功は、現在のChatGPT画面や全ブラウザーでの動作を保証するものではありません。[検証状況と未確認の範囲](verification.md)を確認してください。
