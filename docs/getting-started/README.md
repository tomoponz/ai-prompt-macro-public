# はじめて使う

AI Prompt Macroは、PC版ChatGPTへ事前に決めた指示を順番に送るブラウザ拡張です。ChatGPTの回答本文は読み取りません。このガイドでは、サイドパネルにAIPM Flowを貼り付け、3つの指示を順番に送ります。

```text
指示A → 待機3秒 → 指示B → 待機3秒 → 指示C
```

## 1. 拡張を読み込む

必要なのはPC版ChromeまたはEdge、通常の指示を送信できるChatGPTアカウント、このリポジトリのファイル一式です。APIキーやビルド作業は不要です。

1. GitHubの **Code → Download ZIP** でダウンロードして展開します。Gitを使う場合はcloneしてください。
2. Chromeでは `chrome://extensions`、Edgeでは `edge://extensions` を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**（Load unpacked）を選びます。
5. `manifest.json`があるフォルダーを指定します。

自動実行先はPC版の`chatgpt.com`だけです。スマートフォン、Claude、Geminiの画面は自動操作しません。

## 2. サイドパネルで対象タブを選ぶ

1. `https://chatgpt.com/`を開き、ログインします。
2. 拡張を読み込んだ後、そのChatGPTタブを一度再読み込みします（Ctrl+R）。
3. ブラウザの拡張機能アイコンからAI Prompt Macroのサイドパネルを開きます。
4. **「操作するChatGPTタブ」** で、練習に使うタブを選びます。見つからない場合は **「更新」** を押します。
5. 選択欄には手動の表示名、次にChatGPTのページタイトルを表示します。「操作対象」が送信先で、「表示中」はこのウィンドウの現在のタブです。別のタブを表示しても操作対象は変わりません。同名の会話は実際のタブと照合し、必要なら「詳細」のタブID・会話IDを確認してください。通常の操作でIDを転記する必要はありません。
6. **「接続状態: 対象タブから応答があります」** と表示されることを確認します。別の案内が出ている場合は **「次の操作」** に従ってください。

練習には新しい会話も既存の会話も使えます。新しい会話から始める場合は、最初の送信操作後に対象会話の確認が必要です。

## 3. 必要ならAIに手順を作ってもらう

次の手順4の例を使う場合、この操作は省略できます。自分の目的に合わせた手順をAIに作ってもらう場合は、次の順に操作します。

1. サイドパネルの **「手順を貼り付け」** → **「AIに手順を作ってもらう」** を開きます。
2. **「やりたいこと（任意）」** を入力します。すでにAIとの会話で目的を説明していれば空欄で構いません。
3. **「AI用の作成ガイドをコピー」** を押し、利用中のAIへ自分で貼り付けて渡します。
4. AIから返されたFlowを自分でコピーします。拡張が回答を読み取ったり取り込んだりすることはありません。

コピーに失敗した場合は **「コピー内容・AIPM Flow仕様を見る」** を開き、全文を選択して手動コピーできます。AIに依頼するため別のタブを開いても、実行対象は手順2で選んだタブのままです。

## 4. Flowを貼り付ける

**「手順を貼り付け」** の **「AIが作った手順（AIPM Flow）」** に、次の例またはAIが作ったFlowを貼り付けます。次の例は枠内の本文だけをコピーしてください。

```text
flow todo_practice {
  send """新しい個人向けToDoアプリのアイデアを3つ出してください。"""
  wait 3s
  send """前の回答を踏まえ、最も実現しやすい案を1つ選び、理由を簡潔に説明してください。"""
  wait 3s
  send """選んだ案を1週間で試作する手順を5項目で作ってください。"""
}
```

貼り付けに応じてローカルで検証します。**貼り付けただけでは開始・送信しません。** 説明文やMarkdownの囲みは含めず、エラーがあれば表示された行・列と理由を確認して修正してください。拡張が説明文を切り取ったり、未対応の操作を送信に置き換えたりすることはありません。

現在のFlowには「入力だけして確認」の構文はありません。送信せず入力欄に置く操作は、後述のワークスペースで設定してください。

「前の回答」「選んだ案」を文脈として利用するのはChatGPT側です。拡張が回答を読んで次の指示へ貼り付けるわけではなく、文脈がどこまで保持されるかも保証しません。

## 5. 実行前プレビューを確認する

- 対象が手順2の練習用タブであることを確認します。
- 複数のFlowがある場合は **「実行するFlow」** を選びます。この例では `todo_practice` です。
- **「実行前プレビュー」** の実行範囲がFlow全体、送信予定が `3`、手順が `5` であることを確認します。
- 各手順を展開し、実際に送る指示本文と、指示A → 待機3秒 → 指示B → 待機3秒 → 指示Cの順序を確認します。

形式と上限の検証は、指示の正しさや目的の達成を保証するものではありません。「待機」は生成完了の確認後に追加されます。回答が3秒以内に終わるという意味ではありません。

## 6. 確認した内容で開始する

- ChatGPTの入力欄を空にし、添付もない状態にします。既存の下書きや添付があれば、自分で退避・整理してください。
- 対象タブとプレビューをもう一度確認し、**「この内容で自動送信を開始（3回）」** が使える状態になったら一度押します。
- 開始できない場合は **「理由」「次の操作」** と入力欄付近の案内を確認します。

開始操作が、確認した内容を選択中のタブ用に保存し、保存後の内容と照合してから実行を準備します。手動保存やワークスペースへの往復は不要です。保存失敗・編集競合があれば開始せず、以前の別の内容を代わりに実行しません。

本文・Flow選択・対象を変更した場合は、新しいプレビューを確認してください。編集競合では **「自分の入力をコピー」** で退避し、必要に応じて **「保存済み内容を読み直す」** を使います。この案内は、送信結果不明や実行停止の通知とは別です。

この短い練習では **「スリープ防止」** は通常オフで構いません。実行中は対象タブの会話を変えたり、入力欄・添付を手動編集したりしないでください。

### 新しい会話から開始した場合

最初の送信ボタン操作後に **「確認が必要」** で止まります。会話が作られたという画面変化だけでは、自動継続しません。

1. 同じChatGPTタブで、指示Aが1回だけ送られていることと、その操作で作られた会話を開いていることを確認します。
2. 問題がなければ、サイドパネルの **「再開」** を一度押します。
3. 拡張が対象の会話とページを再確認できた場合だけ、指示Aを既送信の1回として数えて残りへ進みます。指示Aは再送しません。

別の会話に移動した場合や、送信・対象会話に確信がない場合は **「停止」** してください。既存の会話から開始した場合、この新しい会話の確認は発生しません。

## 7. 完了を確認する

サイドパネルが **「完了」**、送信の進捗が `3 / 3` になったら、ChatGPT側で指示A・B・Cと回答を確認します。「完了」は予定した手順を終えた意味で、回答の品質を判定した意味ではありません。

## 同じ指示を繰り返すだけなら

サイドパネルの **「クイック」** を押します。**「AIへの指示」「繰り返し回数」「次の送信まで待つ（秒）」** を設定し、入力欄からフォーカスを外すとタブ別に自動保存されます。指示・送信予定数・対象を確認して **「この内容で自動送信を開始（N回）」** を押してください（Nは送信予定数）。

## 入力だけして確認・詳細編集を使う場合

送信せず入力欄へ指示を置く操作や、部分実行・ライブラリ管理にはワークスペースを使います。

1. サイドパネル上部の **「ワークスペース」** → **「Flow / ワークフロー編集」** を開きます。
2. **「保存済み編集項目」** で同じタブIDを選びます。項目がなければ、サイドパネルで確認した **「正確なタブID」** を入力して **「読み込む」** を押します。ここでの選択は編集内容の保存先で、サイドパネルの操作対象は変わりません。
3. **「ワークフローエディター」** で **「AIへの指示を追加」** を押し、指示と **「動作」** を設定します。**「入力だけして確認」** を選ぶと自動送信せず、入力後に確認待ちで止まります。
4. 必要なら **「待機を追加」** や **「確認ポイントを追加」** を使い、検証結果と順序を確認して **「編集状態を保存」** を押します。保存だけでは開始しません。
5. サイドパネルへ戻り、同じ対象タブの **「保存済み実行内容」** を確認して開始します。

Draftを手動送信してから次へ進む操作、Flowの部分実行、保存競合の扱いは[ユーザーガイド](../user-guide/README.md)を参照してください。

## 止まったとき

まず **「理由」「次の操作」** を読みます。

- **「一時停止」** は次の自動進行を止めます。**「再開」** が使える場合だけ、確認して続けられます。
- **「停止」** はこの自動化を終了します。ChatGPT自身が生成中の回答は止めません。
- 送信結果が不明な場合は、同じ指示を自動再送しません。ChatGPT側で送信有無を確認して「停止」し、必要なら未送信の指示だけを新しく設定します。
- **送信確認済みでも、生成完了を確認できず止まる場合があります。** この場合も同じ指示は自動再送しません。

ページの再読み込み、拡張の再読み込み、ブラウザの完全終了・再起動は別の操作です。再読み込みを繰り返して停止を解除しようとせず、[ユーザーガイド](../user-guide/README.md)の説明を確認してください。
