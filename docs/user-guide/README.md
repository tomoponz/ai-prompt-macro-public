# ユーザーガイド

AI Prompt Macroは、PC版Chrome / Edgeで開いたChatGPTへ、事前に決めた有限の手順を実行する拡張です。自動実行先は`chatgpt.com`だけで、OpenAI APIは使いません。初回は[はじめて使う](../getting-started/README.md)を参照してください。

## どの画面で何をするか

| 画面 | 主な用途 |
| --- | --- |
| サイドパネル「実行コントロール」 | 対象タブの選択、接続・状態・理由・次の操作の確認、開始・一時停止・再開・停止 |
| サイドパネル「クイックプロンプト」 | 同じ指示を指定回数送る簡易入力 |
| サイドパネル「手順を貼り付け」 | AI向けガイドのコピー、Flowの入力・検証・プレビュー、確認した内容で開始 |
| ワークスペース「Flow / ワークフロー編集」 | 画面で組むワークフロー、入力だけして確認、Flowの部分実行、詳細編集・保存、ライブラリ、読み込み・書き出し |
| ワークスペース「実行一覧」 | 保存済みの実行記録を閲覧。現在の接続や実行可否を保証する画面ではありません |
| ワークスペース「ヘルプ・AIヘルパー」 | 使い方の説明、AIにFlow案を作ってもらうための説明文のコピー |
| 「設定」 | 外観と、新しく作成するタブ別の実行内容の既定値 |

実行操作は、サイドパネルの **「操作するChatGPTタブ」** で選んだタブだけが対象です。AIに手順を考えてもらうため別のブラウザタブへ移動しても、実行対象は追従しません。ワークスペースの編集対象を変えても、操作対象は変わりません。

## タブの表示と操作対象

「操作するChatGPTタブ」は、手動の表示名があれば最優先で、その後にChatGPTのページタイトルを表示します。タイトルを取得できない場合、新規会話は「新しいチャット」、それ以外は「ChatGPTタブ #番号」です。タブID・会話ID・接続情報は「詳細」にあります。

「操作対象」は明示的に選んだ送信先、「表示中」はSide Panelと同じウィンドウで表示しているタブです。同名のタイトルでも送信先はタブIDで区別されます。タイトル変更・表示中タブの切替では操作対象を変更しません。

ChatGPTタブのページタイトルは、サイドパネルで見分けるための一時表示にだけ使います。タイトルから送信先や会話の同一性を判断せず、Run・送信記録・診断情報や永続ストレージへ保存しません。開発者へ送信することもありません。ChatGPTの回答本文を読まないOutput-Blindの方針は維持しています。

## クイックプロンプト

サイドパネルで **「クイック」** を押し、次を設定します。

- **「AIへの指示」**: ChatGPTへ送るプロンプト。「よく使う指示」から選ぶこともできます。
- **「繰り返し回数」**: 1〜50回。
- **「次の送信まで待つ（秒）」**: 生成完了を確認した後の追加待機。

入力欄からフォーカスを外すと変更が自動保存されます。開始時にも表示中の入力を保存してから実行内容を確認します。指示・対象タブ・送信予定数を確認して **「この内容で自動送信を開始（N回）」** を押してください（Nは送信予定数）。

## サイドパネルに手順を貼り付ける

**「手順を貼り付け」** では、AIPM Flowの入力から実行前の確認・開始までサイドパネルだけで操作できます。通常のFlow入力にタブIDの転記、ワークスペースへの移動、手動保存は不要です。

1. 必要なら **「AIに手順を作ってもらう」** を開きます。**「やりたいこと（任意）」** を入力し、**「AI用の作成ガイドをコピー」** を押します。すでにAIに目的を伝えていれば空欄で構いません。
2. ガイドを利用中のAIへ自分で渡し、返されたFlowを **「AIが作った手順（AIPM Flow）」** に貼り付けます。AIへの依頼と回答のコピーは利用者が行います。
3. 入力に応じた検証結果を確認します。複数のFlowがある場合は **「実行するFlow」** を選びます。
4. **「実行前プレビュー」** の対象・Flow・実行範囲・送信予定数・待機・確認ポイントと、展開できる各手順の実際の指示本文を確認します。
5. **「この内容で自動送信を開始（N回）」** を一度押します。確認した内容の保存と照合が成功し、対象と開始条件を確認できた場合だけ実行します。

作成ガイドはワークスペースのAIヘルパーと共通です。**「コピー内容・AIPM Flow仕様を見る」** から全文を確認・選択できます。自動コピーに失敗した場合も、ここから手動コピーできます。コピー、貼り付け、検証だけでは実行を開始しません。

### 対応形式・実行範囲

Flow v1.1の対応操作は `send`、有限の `repeat`、`wait`、`wait until`、`checkpoint` です。**Flowには入力だけして確認するDraft構文はありません。** その操作にはワークスペースのワークフローエディターを使ってください。

説明文やMarkdownの囲みを含めず、Flow本文だけを入力します。未対応構文や上限超過があれば、行・列と理由を確認して修正してください。説明文の自動抽出やAIによる自動修復は行いません。「形式と上限を確認済み」は、指示の正しさ・安全性・目的の達成を保証する表示ではありません。

新しく貼った本文はFlow全体が実行範囲になります。保存済みの部分実行を開いた場合は範囲を維持して表示するので、プレビューを確認してください。部分実行の設定変更はワークスペースで行います。`wait until` は例の日付をそのまま使わず、実際の予定と明示的なタイムゾーンを指定してください。過去の指定時刻は開始前にも確認します。

### 開始前の編集と複数画面

開始時には、対象・入力方法・Flow本文・選択・実行範囲を固定し、確認した内容をそのタブへ保存して照合します。保存失敗や競合、開始準備中の内容・対象の変更があれば、新しい実行を開始しません。以前保存されていた別のQuickやFlowを代わりに実行することもありません。新しい内容のプレビューを確認してから、改めて開始してください。

別画面で同じタブの編集内容が更新された場合、未保存変更のないサイドパネルは保存内容を表示します。未保存変更があれば入力を保持して保存・開始を止めます。**「自分の入力をコピー」** で退避し、保存内容を開き直す場合は **「保存済み内容を読み直す」** を使ってください。自動マージや競合の上書きはしません。この編集通知は、実行停止や送信結果不明とは別の案内です。

対象の変更中や対象を確認できない間は開始できません。未保存入力を別のタブへ自動転記しないため、対象を変える場合は画面の案内に従って必要な入力を退避してください。入力方法の切り替えや編集中の変更は、すでに実行中の自動化の内容・送信先を変更しません。一時停止・停止はサイドパネルの実行コントロールから操作します。

## ワークスペースで詳しく編集する

**ワークフロー**は、画面上で手順を追加して組み立てる方式です。**AIPM Flow**は、`send`、`repeat`、`wait`、`wait until`、`checkpoint`などをテキストで記述する方式です。保存形式は異なりますが、Flowも検証後に実行用の手順へ変換されます。どちらも回答内容による分岐はしません。

画面で手順を組む、入力だけして確認する、部分実行を設定する、ライブラリを管理する場合は、サイドパネルの **「ワークスペース」** → **「Flow / ワークフロー編集」** を開きます。同じタブIDの保存済み項目を選ぶか、**「正確なタブID」** を入力して **「読み込む」** を押してください。

### ワークフローエディター

4種類の手順を上から実行します。**「↑」「↓」** で並べ替え、**「×」** で削除します。

| 追加する手順 | 設定と動作 |
| --- | --- |
| AIへの指示を追加 | 指示、動作、繰り返し回数、完了後の待機を設定 |
| 待機を追加 | 「待機時間（秒）」だけ追加で待つ |
| 指定時刻まで待つ手順を追加 | PCのローカル日時、遅れたときの対応、許容する遅れを設定 |
| 確認ポイントを追加 | 「確認時のメッセージ」を表示し、「確認が必要」で止まる |

**「入力して送信」** は、空の入力欄へ指示を書き、内容の一致と安全条件を確認して送信ボタンを1回操作します。既存の下書きや添付は上書きしません。送信確認と生成完了の確認を経て、設定した追加待機へ進みます。

**「入力だけして確認」** は、安全に入力できる空の入力欄へ指示を置きます。送信ボタンは操作せず、**「確認が必要」** で止まります。

1. ChatGPTの入力欄を確認し、必要なら編集します。
2. 送る場合は自分でChatGPT側の送信ボタンを押します。
3. 必要な生成が終わり、次へ進めてよいことを確認します。
4. サイドパネルで **「再開」** を押します。

拡張は、手動で最終的に送った内容や回答本文を読み取って完了を判断しません。

指定時刻に対して許容範囲を超えて遅れた場合、**「確認して停止」** は確認待ち、**「遅れても実行」** は次の手順へ進み、**「遅れたらスキップ」** はその待機手順を飛ばします。PCやブラウザを起動する機能ではありません。

### Flowエディターと保存

**「Flowテキスト」** に記述し、**「検証 / プレビュー」** で対象Flow、実行範囲、送信予定数を確認します。部分実行では、それ以前の会話文脈が必要な場合があります。対象会話と範囲を自分で確認してください。

編集後は **「編集状態を保存」** を押します。これはタブ別の実行内容の保存です。Flowライブラリの **「新規保存」「上書き保存」** は、後で開くためのFlowテキストと名前・説明などの保存であり、別の操作です。

ライブラリから開いたり、テキストを読み込んだりしても自動で開始しません。実行したい内容を編集状態へ保存し、サイドパネルへ戻って同じタブの **「保存済み実行内容」** とプレビューを確認して開始してください。開始ボタンには自動送信の予定回数が表示されます。

別画面の更新と競合したときは入力を保持して保存を止めます。必要な入力を手元に残してから **「保存済み内容を読み直す」** を使ってください。編集中の変更は、すでに実行中の自動化には反映されません。

## 状態・接続・進捗の読み方

| 実行状態 | 意味 |
| --- | --- |
| 待機中 | 現在実行中の自動化がない。接続と開始条件の確認は別途必要 |
| 実行中 | 手順が進行中。指定時刻待ちや追加待機も含む |
| 一時停止中 | 利用者が「一時停止」を押し、安全に再開できる状態 |
| 確認が必要 | 確認ポイント、入力だけして確認、指定時刻の遅れ、新しい会話の確認など。表示に従って確認し、再開可能な場合だけ続ける |
| 安全のため停止 | 送信や対象の安全条件を確認できず、自動継続しない状態。通常の「再開」はできない |
| 完了 | 予定した手順を終えた。回答内容の品質や正しさを判定した意味ではない |
| 停止済み | 「停止」でこの実行を終了した |
| 状態不明 | 保存された状態を判別できない |

**「接続状態」** は実行状態とは別です。一時的な確認失敗で直前の表示を保っている場合もあります。理由と次の操作を読み、接続表示だけで送信済み・未送信を判断しないでください。

サイドパネルの送信進捗には、次の手順へ進む前でも送信確認済みの1回が反映されます。ワークスペースは保存された手順の進捗を表示するため、一時的に数が異なる場合があります。数値だけで再送を決めないでください。

ワークスペースの **「一時停止・確認待ち・安全停止」** は、その3種類を含む絞り込みです。一覧は完全な実行履歴ではなく、保存されているタブ別の実行記録です。

## 止まった理由と次の操作

送信ボタンの操作、送信確認、生成完了の確認は別々です。**送信確認済みという記録は、その後の確認失敗で「送信結果不明」には戻りません。**

| 状況 | 送信について分かること・自動再送 | 次の操作 |
| --- | --- | --- |
| 送信結果が不明 | 送信済み・未送信を断定しない。同じ指示を自動再送しない | ChatGPT側で送信有無を確認して「停止」。必要なら未送信の指示だけで新しく開始 |
| 送信確認済みだが生成完了・次の準備状態を確認できない | 送信は確認済み。同じ指示を自動再送しない | ChatGPT側の生成状態を確認して「停止」。確認済みの指示を再送する設定にしない |
| 対象の会話・ページが同じか確認できない | この理由だけでは送信有無は分からない。送信確認済みの表示があればその確定は維持 | 「停止」し、正しいタブ・会話・ページを確認。送信記録も確認して必要な残りだけを設定 |
| 対象タブに接続できない | 接続不明は送信失敗や実行終了の証拠ではない | 選択したChatGPTタブと「次の操作」を確認。別タブへ自動で切り替えることはない |
| CAPTCHA・ログイン・利用上限・サービスエラー | 制限を回避せず止まる。送信結果は別の記録で判断 | ChatGPT側で正規に対処し、「再開」が使える場合だけ再開。安全停止なら「停止」 |
| 最大送信回数に到達 | 上限を超える自動送信はしない。1回の実行は最大50回 | 内容と送信済みの範囲を確認し「停止」。必要な残りがある場合だけ新しく設定 |
| 同じ会話の同時操作が競合 | 別タブへの切り替えや自動再送はしない | 同じ会話の他の自動化を止め、送信済みの内容を確認して1つだけ使う |

### 新しい会話の最初の送信操作後

新しい会話（プロジェクト内も含む）では、最初の送信ボタン操作後に **「確認が必要」** で止まります。URLが変わっただけでは続行しません。

同じタブで、作成された会話と最初の指示が1回だけ送られたことを確認して **「再開」** を押します。拡張が対象を再確認できた場合だけ、その指示を既送信の1回として数え、残りへ進みます。最初の指示は再送しません。別会話へ移動した場合や確信がない場合は **「停止」** してください。

### 一時停止・再開・停止

**「一時停止」** は以後の自動進行を止めます。送信操作と重なって送信結果が不明になった場合は、再開できない安全停止になることがあります。

**「再開」** は、利用者による一時停止、確認ポイント、入力だけして確認、指定時刻の遅れ、新しい会話の確認など、許可された状態だけで使えます。連打して安全停止を解除しようとしないでください。

**「停止」** はこの自動化の今後の操作を止めます。ChatGPT自身の生成は止めないため、必要ならChatGPT側の停止ボタンを自分で操作します。

## 復旧方針と設定

サイドパネルの **「復旧方針」** は、選択したタブの実行内容に使う設定です。**「標準」** は通常の回数・時間、**「完了を優先」** は上限内で状態確認や準備待ちをより長く行います。完了を保証せず、不明な送信を再試行する設定でもありません。

どちらも対象タブ・会話・ページの確認、同じ会話の同時操作防止、最大50回の自動送信、回答本文を読まない制約は同じです。実行中の設定は変わりません。

**「設定」** の実行の既定値・復旧方針は、新しく作るタブ別の編集内容に使います。保存済みの編集内容と実行中の自動化は変更しません。外観は表示だけに即時反映されます。診断の **「要約」「詳細」** は技術詳細を最初から開くかどうかの設定で、記録内容や安全条件は変わりません。

## 再読み込みと再起動

| 操作・出来事 | 動作と注意 |
| --- | --- |
| ChatGPTページを再読み込み（Ctrl+R） | 同じブラウザ起動中・同じタブ・同じ会話で、安全を確認できる状態だけ復旧可能。送信確認済みの生成待ちや保存済みの待機は継続できる場合がある |
| 送信処理中にページを再読み込み | 送信確認前のまま中断された通常送信は不明として停止し、自動再送しない |
| 新しい会話への最初の送信操作後に再読み込み | 「確認が必要」を維持し、明示的な「再開」まで継続しない |
| サイドパネルの「拡張を再読み込み」 | 開発版更新用。全タブで実行中・一時停止中の自動化がないことを明示的に確認できる場合だけ許可。確認中の重複操作は無視する。更新後はChatGPTページもCtrl+Rする |
| ブラウザ内部で拡張のバックグラウンド処理が再生成 | 同じブラウザ起動中なら保存状態と安全条件を再確認。無条件継続ではない |
| ChatGPTタブを閉じる | そのタブの実行を続行不可にし、指定時刻の予定を解除する |
| Chrome / Edgeを完全終了して再起動 | 以前の実行は自動継続しない。指定時刻の予定とスリープ防止も解除する |

拡張管理画面からの再読み込みには、サイドパネルの確認は適用されません。開発版更新は、すべての自動化を停止してから行ってください。「保存」はブラウザ再起動後の自動継続を意味しません。

## スリープ防止

開始前にサイドパネルの **「スリープ防止」** を有効にすると、実行中だけPC本体の自動スリープを抑えるようブラウザへ要求します。画面の消灯は許可します。一時停止・停止・完了でその実行の要求を解除し、有効な実行が複数あれば最後の1つが止まるまで維持します。

すでにスリープ・休止・電源オフのPCを起こしません。手動スリープ、蓋を閉じる操作、OSや組織の設定を必ず上書きする保証もありません。PCが実際にスリープすると自動実行は進みません。

## 保存・複数タブ・プライバシー

編集内容と実行状態はタブ別です。表示名・グループ・識別色は見分けるためだけに使い、送信先や安全判定には使いません。異なる会話なら並行実行できますが、同じ会話を複数の自動化から同時操作することは防ぎます。

データは拡張のローカル保存領域へ保存します。タブを閉じるとそのタブの編集状態を削除し、ブラウザの完全再起動ではタブ別編集状態と選択対象を消去します。Flowライブラリへ明示保存したテキストと名前・説明などは別の保存領域に残ります。クラウド同期はしません。

ChatGPTの回答本文は取得・保存・解析・書き出しせず、回答による条件分岐にも使いません（**Output-Blind**）。入力欄、送信・生成状態の操作部品、限定された制限・確認画面、会話識別に必要なURL情報を確認します。回答本文を読む権限をブラウザが物理的に遮断する仕組みではなく、ソースとテストで監査する実装上の制約です。

独自サーバー、利用状況の外部収集、外部コードの実行はありません。実際に送信した指示は通常のChatGPT利用としてChatGPT側へ送られ、アカウントの料金・制限・規約が適用されます。詳しくは[Privacy](../../PRIVACY.md)と[Security](../../SECURITY.md)を参照してください。

ChatGPTの画面構造が変わると、安全に確認できず止まる場合があります。自動テストやブラウザfixtureの成功は実ChatGPTへの対応証明ではありません。リリース時は[PC Release Checklist](../release/PC_RELEASE_CHECKLIST.md)の実ブラウザ確認を別途行います。
