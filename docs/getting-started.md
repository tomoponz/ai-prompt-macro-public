# はじめて使う

AI Prompt Macro（APM）は、PC版ChatGPTへ、あらかじめ決めた指示を順番に入力・送信するブラウザ拡張機能です。APIキーは不要です。回答本文を読み取ったり、出来栄えを評価したりはしません。

このガイドでは、3つの指示を送る短い例を使って基本操作を説明します。**0.4.4の実ChatGPTでの最終動作確認は未実施です。** 自動テストの確認範囲と実サービスでの確認状況は[検証について](verification.md)に分けて記載しています。

## 1. 拡張を読み込む

PC版ChromeまたはEdge、通常の指示を送れるChatGPTアカウント、このリポジトリのファイル一式を用意します。ビルド作業は不要です。

1. GitHubの **Code → Download ZIP** でダウンロードして展開します。Gitを使う場合はcloneします。
2. Chromeでは `chrome://extensions`、Edgeでは `edge://extensions` を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**（Load unpacked）を選び、`manifest.json` のあるフォルダーを指定します。

自動操作の対象はPC版の `chatgpt.com` だけです。スマートフォンやClaude、Geminiの画面は操作しません。

既存版を更新する場合は、下書き・未保存入力・必要な診断を先に退避し、全タブの実行を **「停止」** してください。拡張機能の更新後はChatGPTタブも再読み込みする必要があります。[0.4.4の更新手順](releases/0.4.4.md)に沿って進めてください。

## 2. サイドパネルで対象タブを選ぶ

1. `https://chatgpt.com/` を開いてログインします。拡張機能を読み込む前から開いていたタブは、一度再読み込みします。
2. ブラウザの拡張機能アイコンからAPMのサイドパネルを開きます。
3. **「操作するChatGPTタブ」** で対象を選びます。見つからない場合は **「更新」** を押します。
4. **「接続状態: 対象タブから応答があります」** と表示されることを確認します。別の案内が出ていれば **「次の操作」** を読みます。

**「操作対象」** に表示されているタブが送信先です。別のブラウザタブを表示しても、対象は自動で切り替わりません。同名の会話がある場合は実際のタブと照合し、必要なら **「詳細」** のタブID・会話IDを確認します。通常の開始操作でIDを手作業で転記する必要はありません。

新しいチャットでは、そのままAPMを開始できません。手順4の最初の指示をChatGPTで手動送信し、回答が終わってから残りの指示をAPMで実行します。通常の新規チャットとProject内の新規チャットは、どちらも同じ扱いです。

## 3. 必要ならAIに手順を作ってもらう

手順4のサンプルをそのまま使う場合は、この手順を飛ばせます。

1. **「手順を指定」** → **「AIに手順を作ってもらう」** を開きます。
2. **「やりたいこと（任意）」** に目的を書きます。AIとの会話ですでに説明していれば空欄でも構いません。
3. **「AI用の作成ガイドをコピー」** を押し、使いたいAIへ自分で貼り付けます。
4. AIが出力したAIPM Flowを自分でコピーします。

APMが直接AIへ作成を依頼したり、回答を自動で取り込んだりする機能ではありません。自動コピーに失敗した場合は **「コピー内容・AIPM Flow仕様を見る」** から全文を手動コピーできます。

## 4. Flowを貼り付ける

**「手順を指定」** の **「AIが作った手順（AIPM Flow）」** に、次の枠内の本文を貼り付けます。

```text
flow todo_practice {
  send """新しい個人向けToDoアプリのアイデアを3つ出してください。"""
  wait 3s
  send """前の回答を踏まえ、最も実現しやすい案を1つ選び、理由を簡潔に説明してください。"""
  wait 3s
  send """選んだ案を1週間で試作する手順を5項目で作ってください。"""
}
```

**貼り付けただけでは送信されません。** 前後の説明文やMarkdownのコードブロック記号（```）は含めず、エラーが出た場合は表示された行・列と理由を確認して修正します。

新しい会話で試す場合は、最初の「アイデアを3つ出してください」という指示をChatGPTで一度手動送信します。送信と回答の完了を確認したら、Flowの最初の `send` と直後の `wait 3s` を削除してください。残すのは、案を選ぶ指示 → 待機3秒 → 試作手順を作る指示です。

**手動で送った分は自動で差し引かれません。** ほかのFlowや単純繰り返しでも、残りの手順・回数を自分で調整します。なお、「前の回答」を文脈として扱うのはChatGPT側であり、APMが回答を読み取って次の指示に渡しているわけではありません。

## 5. 実行前プレビューを確認する

入力欄の下にある送信回数と手順数を確認し、**「実行内容の詳細」** を開きます。複数のFlowがある場合は **「実行するFlow」** も選びます。

| この例の使い方 | 送信回数 | 手順数 |
| --- | --- | --- |
| 既存の会話で、例をすべてAPMから送る | 3回 | 5個 |
| 最初を手動送信し、最初のsendとwaitを削除した | 2回 | 3個 |

対象タブ・選んだFlow・実行範囲と、展開できる各指示の全文を確認してください。形式と上限の検証は、指示内容の正しさや回答品質を保証するものではありません。`wait 3s` は回答の生成完了後に追加で3秒待つ指定です。

## 6. 確認した内容で開始する

1. ChatGPTの入力欄を確認します。**入力欄にある文章やプラグイン名などを残した末尾へ、最初の指示を追記して一緒に送ります。** 送るつもりのない内容は退避してください。未送信の添付や進行中のファイル追加がないことも確認します。
2. 対象とプレビューを確認し、**「この内容で自動送信を開始（N回）」** が有効になったら一度押します。Nはこれから自動送信する回数です。
3. 開始できないときは、入力欄付近の案内と **「理由」「次の操作」** を読みます。

開始時に表示中の内容を保存・照合するため、事前の手動保存は不要です。保存失敗や別画面との編集競合があれば開始しません。競合した入力は **「自分の入力をコピー」** で退避し、必要なら **「保存済み内容を読み直す」** を使います。

実行中は、対象タブで会話を切り替えたり、入力欄や添付を手動編集したりしないでください。元の入力を保てない場合や長文が添付になった場合の条件は、[ユーザーガイドの入力と添付の説明](user-guide.md#ワークフローエディター)を参照してください。既存の未確認添付を自動送信する機能ではありません。

### 以前のRunが新しい会話の確認待ちで残っている場合

これは、旧Run（1回の実行記録）が最初の送信後に **「確認が必要」** で残っている場合だけの互換手順です。

同じタブで、その操作によって作られた会話であり、最初の指示が1回だけ送られていることを確認したうえで **「再開」** を一度押します。対象を再確認できれば、その指示を送信済みとして数え、再送せずに残りの手順へ進みます。別の会話に移動した場合や確信が持てない場合は **「停止」** してください。

この互換手順と、新規Runの開始前に手動送信した分を差し引く操作は別です。新規Runでは手順4のとおり自分で回数を調整します。

## 7. 完了を確認する

**「完了」** と表示されたら、ChatGPT側で送信された指示と回答を確認します。この例の自動送信進捗は、すべてAPMから送った場合は `3 / 3`、最初を手動送信した場合は `2 / 2` です。手動送信分は進捗に含まれません。

「完了」は予定した手順を終えたという意味です。回答が適切か、そのまま採用するかは利用者が判断します。

## 同じ指示を繰り返すだけなら

**「単純繰り返し」** で **「AIへの指示」「繰り返し回数」「追加の待機（秒）」** を設定します。回数は1〜50回、待機は生成完了後の追加時間です。入力欄からフォーカスを外すと自動保存され、開始時にも保存・照合されます。対象と予定回数を確認して開始してください。

## 入力だけして確認・詳細編集を使う場合

Flowには、送信せずに入力欄へ置くだけの構文はありません。**「ワークスペース」** → **「Flow / ワークフロー編集」** の **「ワークフローエディター」** を使います。

1. **「保存済み編集項目」** で同じタブを選びます。項目がなければ、サイドパネルの **「詳細」** で確認したタブIDを **「正確なタブID」** に入力し、**「読み込む」** を押します。
2. **「AIへの指示を追加」** で指示を書き、**「動作」** を **「入力だけして確認」** にします。
3. **「編集状態を保存」** し、サイドパネルへ戻ります。同じ対象タブの **「保存済み実行内容」** を確認して開始します。

この操作は空の入力欄に対してのみ動作し、入力後に確認待ちで止まります。再開の仕方・部分実行・ライブラリ保存は[ユーザーガイド](user-guide.md)を参照してください。

## 止まったとき

まず **「理由」「次の操作」** とChatGPT側の状態を確認します。

- **「一時停止」** は以降の自動進行を止めます。**「再開」** が有効な場合だけ続けられます。
- **「停止」** はAPMの実行を終了します。ChatGPT自身の回答生成は止めません。
- 送信結果が不明な場合、同じ指示を自動再送しません。ChatGPT側で送信有無を確認して停止し、必要なら未送信の指示だけを新しく設定します。
- 送信確認済みでも、生成完了や対象の確認ができずに止まる場合があります。「送れなかった」と判断してそのまま再送しないでください。
- ページ側が止まっていても、停止要求を現在のRunのものと確認できず、保存表示が **「実行中」** のまま残る場合があります。必要な診断を保存し、対象と送信済みの範囲を確認して **「停止」** します。

開始・再開や再読み込みの連打で解消しようとせず、[止まった理由と次の操作](user-guide.md#止まった理由と次の操作)を確認してください。ページ・拡張の再読み込みとブラウザの完全再起動は、[それぞれの扱いが異なります](user-guide.md#再読み込みと再起動)。
